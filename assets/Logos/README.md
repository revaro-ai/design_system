# Logos

Version 1 of the logo, chosen 8 October 2026: "revaro." in Rubik Medium, tightened 2%, with a terracotta full stop the width of a stem. Not trademark-checked yet.

- `revaro-wordmark.svg`: slate wordmark with the `brand-dot` full stop, for light backgrounds.
- `revaro-wordmark-reversed.svg`: stone wordmark on a slate panel, with the lighter dot (#c8653a) so it stays visible on dark.
- `revaro-app-icon.svg`: "r." on slate, set as one word so the dot sits on the baseline, centred as a pair.
- `revaro-favicon.svg`: the same icon drawn larger in its square so it holds up at 16 and 32px.

PNG exports for places that can't use SVG:

- `revaro-app-icon-512.png` and `revaro-app-icon-192.png`: the web app manifest icons (Android home screen, install prompt).
- `apple-touch-icon-180.png`: square, no rounded corners, because iOS rounds them itself.

The text is outlined, so none of these need Rubik installed. Keep clear space of one x-height on every side. Minimum width for the wordmark is 72px; below that use the icon. Don't recolour the dot, swap it for another shape, or put the slate wordmark on a dark background (use the reversed one).

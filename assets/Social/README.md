# Social

The 1200×630 link preview for revaro.ai and for sharing on Facebook, Messenger and Telegram, drawn for the 0.4 logo. Use `revaro-share-card.png` as the Open Graph image (`og:image`); most platforms won't read SVG. `revaro-share-card.svg` is the editable source. The line on it is the current value proposition; change both together.

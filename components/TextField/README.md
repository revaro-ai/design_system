# TextField

A labelled input with room for a hint or an error underneath.

The label is always visible; a placeholder is an example, not a label. Text is 16px so phones don't zoom in. Set `inputmode` (numeric for prices, tel for phones) so the right keyboard comes up. Accept Burmese and Latin digits and store Latin. When something's wrong, the hint turns into the error and says how to fix it: "Phone number looks too short", not "Invalid input".

# EmptyState

What a screen shows when there's nothing in it, or when it couldn't load.

One icon, one short title, one sentence, and at most one button. An empty queue is good news, so say it plainly ("Nothing to confirm") rather than apologising. The error version says what went wrong in normal words, reassures where it can ("Nothing has been lost"), and offers a retry.

- No illustrations; the brand book rules them out.
- Never show an empty list without a message. Sellers will think something is broken.

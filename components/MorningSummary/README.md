# MorningSummary

The first thing the seller sees after a night of Revaro selling: what happened, what needs her, one button to start.

Order on the card: the time window and the count of orders ready, then payments to check, chats that need her, and paid-but-no-stock (shown even at zero, so she knows it was checked), then what sold out. If anything broke overnight, an Alert goes above all of it. One button at the bottom opens the queue.

The same summary goes to the owner as a short Burmese message on Viber or Telegram, with a link back in.
